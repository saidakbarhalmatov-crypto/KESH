# KESH — Личный учёт финансов (React Web)

Персональное веб-приложение для учёта доходов и расходов в сомах (KGS) с полноценной системой аниме-тем, аналитикой, распознаванием чеков (OCR) и ИИ-ассистентом.

## Возможности

- **Система аниме-тем оформления (6 персонажей + 2 базовые темы)**:
  - **Itachi** — трон Учихи под красной луной с воронами, Шаринганом на карточке баланса, гербом клана Учиха, облаками Акацуки на экране чеков и тёмными карточками с алым свечением.
  - **Madara** — пламя Сусаноо и Вечный Мангекё Шаринган.
  - **Gojo** — Безграничность, Шесть Глаз и неоновые сферы.
  - **Yuta Okkotsu** — тёмный Токио, катана и фиолетовая проклятая энергия.
  - **Mikasa** — Крылья Свободы, сумрачный графит и алый шарф.
  - **Marin** — тёплый закат над Токио и мягкие огни.
  - **Тёмный Графит** и **Светлая классика** — минималистичные режимы без иллюстраций.
- **Учёт операций**: добавление доходов и расходов вручную, фильтрация, поиск и удаление.
- **Аналитика**: круговая диаграмма с тематическим центром, разбивка по категориям и счетам.
- **Распознавание чеков (OCR)**: загрузка изображений чеков и авторазбор текста квитанций.
- **ИИ-помощник**: распознавание текстовых и голосовых команд, а также фото чеков через Gemini API (с локальным резервным разбором).
- **Хранение и экспорт**: сохранение данных и настроек в `localStorage` браузера, экспорт истории в CSV.

## Запуск

```bash
npm install
npm run dev
```
